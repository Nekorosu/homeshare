# homeshare

# ЖЁСТКИЕ ПРАВИЛА ВЫПОЛНЕНИЯ ЗАДАЧ

## 1. Рабочая директория — ТОЛЬКО репозиторий пользователя
Перед любым действием выполни и покажи вывод:
  pwd
  git rev-parse --show-toplevel
  git branch --show-current
  git status --porcelain
Если git rev-parse упал — СТОП. Ты не в репозитории. Сообщи мне и жди указаний.

## 2. Запрещено утверждать "сделано" без доказательства
После ЛЮБОГО изменения файлов выполни и покажи РЕАЛЬНЫЙ вывод:
  git status --porcelain
  git diff --stat
  ls -la <созданные_файлы>

После ЛЮБОГО коммита выполни и покажи РЕАЛЬНЫЙ вывод:
  git log -1 --stat --oneline
  git rev-parse HEAD
  git branch --contains HEAD

## 3. Проверка коммита — ОБЯЗАТЕЛЬНА
Коммит считается созданным ТОЛЬКО если:
  - git log -1 показывает его хеш
  - git branch --contains HEAD показывает ТЕКУЩУЮ ветку
  - git show --stat HEAD содержит ожидаемые файлы
Если хотя бы одно условие не выполнено — напиши "КОММИТ НЕ СОЗДАН" и причину.

## 4. Запрещено:
  - писать "готово" / "создано" / "закоммичено", если проверка провалена;
  - ссылаться на хеш/файл, которого нет в выводе git/ls;
  - молчать об ошибках shell-команд;
  - создавать файлы вне git rev-parse --show-toplevel.

## 5. Если инструмент записи упал или не вызвался
Явно напиши: "Не удалось создать файл X. Ошибка: <текст>. Действие не выполнено."
НЕ пиши "файл создан", если write_file/edit_file не вернул успех.

## 6. Формат ответа после выполнения
  [ПУТЬ] pwd: ...
  [ПУТЬ] toplevel: ...
  [ВЕТКА] ...
  [ФАЙЛЫ] список созданных с ls -la
  [GIT STATUS] вывод git status --porcelain
  [COMMIT] хеш + git log -1 --stat
  [ВЕРИФИКАЦИЯ] OK / FAIL + причина
